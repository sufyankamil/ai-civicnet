1. Purpose of encryption

CivicNet uses cryptography solely to protect private chat message content between users who have been matched for community help requests.

Encryption is used for confidentiality of chat message payloads and wrapping per-conversation symmetric keys for conversation participants.

Encryption is not used for DRM, proprietary protocols, or concealing malware.

2. Cryptographic algorithms

All algorithms are industry-standard. CivicNet does not implement proprietary or non-standard cryptography.

UseAlgorithmKey size / paramsStandard
Chat message encryption AES in CBC mode 256-bit key, 128-bit IV NIST FIPS 197 / ISO/IEC 18033-3
Conversation key wrap RSA-OAEP 2048-bit RSA, OAEP with SHA-256 PKCS #1 v2.2 / IETF RFC 8017
Transport to backend TLS (HTTPS) As negotiated by iOS IETF TLS — Apple OS networking

Legacy dual-read (migration only): older messages may still be decrypted with a former app-wide AES-256-CBC key during a limited migration window. New messages use per-conversation keys only.

3. Where cryptography is implemented

LayerImplementation
Message & key-wrap crypto Client app (Flutter / Dart) via open-source libraries encrypt and pointycastle
Private key storage iOS Keychain via flutter_secure_storage
Network transport Apple OS TLS / HTTPS to Supabase and Firebase

Chat cryptography is implemented in the application, in addition to Apple OS HTTPS.

4. What is encrypted

  • Encrypted: chat message body ciphertext; per-conversation AES keys wrapped under each participant’s RSA public key
  • Not encrypted by custom app crypto: public discovery profile fields; push notification bodies (generic text only)

Key lifecycle:

  1. Each device generates an RSA-2048 identity key pair; public wrap key is stored on the user profile.
  2. When a conversation starts, a random 256-bit conversation key is generated.
  3. That key is RSA-OAEP wrapped for each participant and stored server-side as opaque ciphertext.
  4. Messages are AES-256-CBC encrypted with the conversation key; ciphertext is Base64(IV ‖ ciphertext).
